```
[ 업무 ]  입출고 | 재고
```

## 업무

### 입출고 (v1.0.30~, 태그: `receive_issue`)

입고와 출고를 **한 화면**에서 처리합니다. (v1.0.30 이전에는 입고·출고가 별도 탭이었음)

| 기능 | 설명 |
|------|------|
| 모드 전환 | 상단 라디오/세그먼트로 **입고** ↔ **출고** 전환 |
| 새 전표 | Expander 안에서 품목 검색 → 담기 → 저장. 출고 시 **사용부서·사용자** |
| 최근 전표 | 기본 **전체**. 유형 필터 칩은 직접 눌렀을 때만 입고/출고로 걸러 줌. 입고는 **공급업체**, 출고는 **사용자**, 전체는 둘 다 표시. **더블클릭**은 현재 새 전표에 품목만 넣음. Ctrl/Shift **다중 선택·일괄 삭제** |
| 수정·삭제 | 선택 전표 **수정**(삭제 후 재저장) 또는 **삭제** |
| 권한 | 입고만/출고만 권한이 있으면 해당 세그먼트만 표시 |

**v1.0.31 수정:** 입고일·출고일 DatePicker를 별도 컨트롤로 분리 (중복 부착 크래시 해결).

### 재고 (태그: `stock`)

| 기능 | 설명 |
|------|------|
| 재고 목록 | 품목별 현재고, LOT(해당 품목), 유효기간 |
| 필터·검색 | 분류, 부족 재고 등 |
| LOT 상세 | Expander로 LOT별 수량·유효기간 |
| 삭제 | 선택 품목을 목록에서 숨김 (현재고가 남아 있으면 거부). 입고 권한 |
| 입출고 바로가기 | 품목 선택 후 **입출고 화면으로 이동**(품목 프리필) |

## 분석

### 대시보드 (태그: `dashboard`)

| 기능 | 설명 |
|------|------|
| KPI 카드 | 구매·출고·재고 관련 요약 수치 |
| 품목별 그래프 | 품목 선택 시 **월별 출고 추이** 비교 (작은 그래프) |
| 테스트 데이터 | (관리자) 샘플 데이터 생성·다시 만들기 — **설정 > 개발자** Expander로 이동 (운영 UX 분리) |

### 통계·보고서 (태그: `stats`)

| 기능 | 설명 |
|------|------|
| 기간 조회 | 년·월·일 단위 |
| 필터 | 즉시 반영 (v1.0.19~) |
| 추이 비교 | 기간·부서별 추이 |
| 숫자 표시 | 사용·입고·구매금액 가독성 개선 (v1.0.18) |

> 연도가 다른 같은 달은 **합치지 않습니다.**

## 관리

### 백업·복원 (태그: `backup`)

| 기능 | 설명 |
|------|------|
| DB 백업·복원 | 로컬 파일 |
| Excel 가져오기 | `마스터만`, `마스터+기초`, `전체이력` |
| Excel 내보내기 | 수불·마스터 |
| 품목 추가 | Excel 가져오기가 주요 경로 (품목마스터 시트) |

품목마스터 열: 1=품목코드, 2=품목명, 3=분류, 4=규격/단위, 5=참고단가, 6=기본사용부서(선택), 8=최소재고

### 환경설정 (태그: `settings`)

| 기능 | 설명 |
|------|------|
| 경고일 | 유효기간 경고 |
| 백업 폴더 | 경로 설정 |
| 업데이트 | GitHub Releases에서 확인·적용 |
| 개발자 (관리자) | 테스트 데이터 다시 만들기 (`ReplaceSample`) |

### 사용자 (태그: `users`)

| 기능 | 설명 |
|------|------|
| 계정 관리 | 사용자 추가·역할 변경 |
| 로그인 | **사용하지 않음** (v1.0.27~). 작업 기록용 계정 관리 |
