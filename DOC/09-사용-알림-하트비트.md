# 09 — 사용 알림(하트비트) 메일

앱 시작 시 **하루 1회**, 개발자 메일로 설치·사용 알림만 보냅니다. 재고·거래·환자 정보는 포함하지 않습니다.

## 수신

- 고정: `pjm7908@hanmail.net`

## 포함 항목

| 항목 | 필수 |
|------|------|
| 설치 ID (PC당 GUID, AppData) | 예 |
| 앱 버전 (`ProductInfo.Version`) | 예 |
| 전송 시각 (로컬) | 예 |
| PC 이름 / Windows 사용자 | 선택 |
| 의원/앱 이름 (`Settings.ClinicName` 없으면 표시명) | 선택 |

## SMTP (한메일/다음)

- 호스트: `smtp.daum.net`
- 포트: `465` (SSL, 기본) 또는 `587` (STARTTLS)
- **일반 로그인 비밀번호가 아니라 한메일 앱 비밀번호**가 필요합니다.
- 소스 코드·git에 비밀번호를 넣지 마세요.

### 설정 방법

1. **앱 설정 > 사용 알림**  
   - 「사용 알림 보내기」 체크(기본 ON)  
   - SMTP 발신(From), 호스트, 포트, 앱 비밀번호 입력 후 저장  
   - 비밀번호는 Windows DPAPI로 `%LOCALAPPDATA%\SpringClinicInventory\usage-notify.json`에 저장됩니다.

2. **또는 로컬 설정 파일**  
   - 예시: [config/usage-notify.example.json](../config/usage-notify.example.json)  
   - 복사 위치: `%LOCALAPPDATA%\SpringClinicInventory\usage-notify.json`  
   - `Password`에 앱 비밀번호를 넣은 뒤 저장 (이 파일은 gitignore 대상·AppData에만 둠)

### 미설정 시

SMTP From/비밀번호가 없으면 **발송만 건너뛰고** 로그에 한 번 남깁니다. 입고·출고 등 업무는 그대로 됩니다.

## 관련 파일

- `InstallIdentity` / `UsageNotifyOptions` / `UsageHeartbeatService` (`Inventory.Infrastructure`)
- 시작 훅: `MainWindow` Loaded
- 테스트: `UsageHeartbeatTests` (실제 SMTP 호출 없음)
