# 09 — 사용 알림(하트비트) 메일

앱 시작 시 **하루 1회**, 개발자 메일로 설치·사용 알림만 보냅니다. 재고·거래·환자 정보는 포함하지 않습니다.

## 수신

- 고정: `pjm7908@hanmail.net`

## 포함 항목

| 항목 | 필수 |
|------|------|
| 설치 ID (PC당 GUID, AppData) | 예 |
| 앱 버전 (`ProductInfo.Version`) | 예 |
| 전송 시각 (로컬) | 예 |
| PC 이름 / Windows 사용자 | 선택 |
| 의원/앱 이름 (`Settings.ClinicName` 없으면 표시명) | 선택 |

## SMTP (한메일/다음)

- 호스트: `smtp.daum.net`
- 포트: `465` (SSL, 기본) 또는 `587` (STARTTLS)
- **일반 로그인 비밀번호가 아니라 한메일 앱 비밀번호**가 필요합니다.

### 기본 내장 (의원 PC)

앱에 **From·앱 비밀번호·SMTP 호스트/포트** 기본값이 내장되어 있습니다. 설정 화면에서 따로 입력하지 않아도 사용 알림이 발송됩니다.

- 기본 From: `pjm7908@hanmail.net`
- 비밀번호: 컴파일된 `UsageNotifyDefaults`(XOR+Base64 난독화). git의 `example.json`에는 평문을 두지 않습니다.
- **보안 한계:** 디컴파일·메모리 덤프로 복원 가능합니다. 개발자 전용 send-only 앱 비밀번호로만 쓰고, 유출 시 한메일에서 앱 비밀번호를 재발급하세요.

### 설정에서 덮어쓰기

1. **앱 설정 > 사용 알림**  
   - 「사용 알림 보내기」 체크(기본 ON)  
   - SMTP 발신(From), 호스트, 포트, 앱 비밀번호를 넣으면 내장 값을 덮어씁니다.  
   - 비밀번호 칸을 비우면 저장된 사용자 값(있으면)을 유지하고, 사용자 값이 없으면 **내장 기본값**을 씁니다.  
   - 사용자 비밀번호는 Windows DPAPI로 `%LOCALAPPDATA%\SpringClinicInventory\usage-notify.json`에 저장됩니다.

2. **또는 로컬 설정 파일**  
   - 예시: [config/usage-notify.example.json](../config/usage-notify.example.json)  
   - 복사 위치: `%LOCALAPPDATA%\SpringClinicInventory\usage-notify.json`  
   - `Password`는 선택(덮어쓰기용). 비우면 내장 기본값 사용.

### 알림을 끄려면

설정에서 「사용 알림 보내기」를 해제하면 발송하지 않습니다. 입고·출고 등 업무는 그대로입니다.

## 관련 파일

- 시작 훅: `MainWindow` Loaded
- 테스트: `UsageHeartbeatTests` (실제 SMTP 호출 없음)
