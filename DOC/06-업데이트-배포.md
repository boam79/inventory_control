# 06 — 업데이트·배포

## 배포 방식 요약

| 단계 | 도구 | 결과물 |
|------|------|--------|
| 테스트 | `dotnet test` | 101개 테스트 통과 |
| 게시 | `dotnet publish` | `publish/` self-contained exe |
| 패키징 | Velopack `vpk pack` | `dist/*Setup.exe`, nupkg, JSON 피드 |
| 배포 | GitHub Releases | Setup.exe + sha256 + Velopack 메타 |

---

## Setup.exe 빌드 (개발 PC)

```powershell
powershell -ExecutionPolicy Bypass -File scripts/pack-installer.ps1
```

기본 버전은 스크립트의 `$Version`(현재 `1.0.31`)과 `ProductInfo.Version`을 맞춥니다.

### 스크립트가 하는 일

1. `dotnet test` — 실패 시 중단
2. `dotnet publish Inventory.App -c Release -r win-x64 --self-contained true`
3. `vpk pack` — Setup.exe, 바로가기(바탕화면·시작메뉴)
4. SHA256 해시 파일 생성 (`*.sha256`)

### 출력 (`dist/`)

| 파일 | 용도 |
|------|------|
| `*Setup.exe` | **의원 PC 설치** (더블클릭) |
| `*.sha256` | 무결성 검증 |
| `releases.win.json`, `assets.win.json` | Velopack 인앱 업데이트 피드 |
| `*.nupkg`, `RELEASES` | Velopack delta 업데이트 |

> 큰 exe는 **git에 커밋하지 않습니다.** 빌드 스크립트만 저장소에 있습니다.

## GitHub Releases 업로드

```powershell
gh release create v1.0.31 dist/*Setup.exe dist/*.sha256 dist/*.nupkg dist/RELEASES dist/releases.win.json dist/assets.win.json `
  --repo boam79/inventory_control --title "v1.0.31" --notes "입출고 DatePicker 크래시 수정"
```

**릴리스 페이지:** https://github.com/boam79/inventory_control/releases

## 의원 PC에서 업데이트

### 방법 1 — 인앱 업데이트 (권장)

1. 앱 실행 시 **업데이트 안내 팝업** (v1.0.29~) 또는
2. 상단/환경설정 **「업데이트」** 버튼
3. GitHub Releases에서 패키지 다운로드 → SHA256 검사 → 적용 → **재시작**

### 방법 2 — Setup.exe 재설치

- Releases에서 최신 `SpringClinic.Inventory-win-Setup.exe` 다운로드
- 더블클릭 설치 (DB는 AppData에 그대로 유지)

### Velopack 동작

- 설치본만 자동 적용 (`dotnet run` 개발 실행은 **적용 안 함**)
- 실패해도 **현재 실행 중인 프로그램은 그대로** — 재고 업무 계속 가능

## GitHub API Rate Limit (403) 대응

**문제:** `api.github.com`으로 최신 릴리스 조회 시 IP당 한도 초과 → 403

**해결 (v1.0.23~):**

- Velopack **CDN 다운로드 URL** 사용 (`LatestDownloadBase`)
- `releases.win.json` 직접 fetch — API 호출 최소화
- 403 시 사용자에게 **한도 초과 안내** + Setup.exe 직접 다운로드 URL 표시

## 버전 올릴 때 체크리스트

1. `Inventory.Core/ProductInfo.cs` → `Version` 수정
2. `scripts/pack-installer.ps1` → `$Version` 수정
3. `dotnet test` 통과
4. `pack-installer.ps1` 실행
5. `git commit` + `git tag vX.Y.Z` + `git push` + `git push --tags`
6. `gh release create` 로 dist 업로드

**문서만 변경(DOC/)할 때는 버전 bump·릴리스 불필요.**
