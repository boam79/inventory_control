## 알려진 제한·주의사항

### 운영

| 항목 | 설명 |
|------|------|
| 단일 PC | SQLite 로컬 DB — 동시 다중 PC 공유 미지원 |
| 로그인 없음 | PC 물리 접근 = 전체 권한에 가까움. PC 잠금 권장 |
| SmartScreen | 서명 없는 exe — 설치 시 경고 가능 |
| 오프라인 | 업데이트 확인만 실패, **재고 업무는 오프라인 가능** |

### 개발

| 항목 | 설명 |
|------|------|
| WPF DatePicker | **동일 UIElement를 두 `Field()`에 넣지 말 것** — 크래시 (v1.0.30 교훈) |
| Mac에서 WPF | 화면·Setup.exe 불가. 테스트·도메인은 가능. → [08-맥-윈도우-개발환경.md](./08-맥-윈도우-개발환경.md) |
| TableGrid | tuple / ColumnSpec overload 혼용 시 CS1503 — ColumnSpec 전용 사용 |
| ReceiveIssueView | `PendingLaunch` 소비 전 launch 변수 별도 보관 필요 |
