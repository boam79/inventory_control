# 01 — 프로젝트 개요

## 프로그램 이름

**스프링의원 재고관리** (`SpringClinic.Inventory`)

## 목적

스프링의원에서 사용하는 **의료소모품·시술재료 재고**를 Windows PC 한 대에서 관리하는 **오프라인 우선** 데스크톱 프로그램입니다.

### 핵심 원칙

- 재고는 **의원 단일 창고** 기준입니다. 출고 시에만 사용 부서를 기록합니다.
- 초기재고가 비어 있으면 0이 아니라 **「미설정」**으로 표시합니다.
- 거래(입고·출고)는 **물리 삭제하지 않고** 취소·수정·삭제(반대 처리)로 처리합니다.
- **환자 식별정보는 저장하지 않습니다.**
- 예측·자동 업데이트가 실패해도 **입고·출고 업무는 계속**됩니다.
- 자동 발주 확정 기능은 없습니다.

## 기술 구성

| 구분 | 기술 |
|------|------|
| UI | WPF (.NET 10, Windows 전용) |
| DB | SQLite (로컬 파일, EF Core 마이그레이션) |
| 설치·업데이트 | Velopack (`vpk` 1.2.0) |
| 로그 | Serilog (파일) |
| 테스트 | xUnit (현재 101개 통과) |
| 배포 | GitHub Releases (`boam79/inventory_control`) |

### 솔루션 구조

```
SpringClinicInventory/
├── Inventory.App/          # WPF 메인 앱 (화면, 업데이트 UI)
├── Inventory.Core/         # 제품 정보, 역할·권한, UI 레이아웃 상수
├── Inventory.Infrastructure/  # DB, 재고 서비스, Excel, 백업, 예측, 업데이트
├── Inventory.Tests/      # 단위·통합 테스트
├── scripts/
│   ├── pack-installer.ps1  # Setup.exe 빌드
│   └── install-shortcut.ps1
└── DOC/                    # 이 문서 폴더
```

## 시스템 요구 사항

### 의원 PC (설치본)

- Windows 10/11 64비트
- .NET SDK **불필요** (self-contained 배포)

### 개발 PC

- .NET 10 SDK
- 로컬 도구: `vpk` 1.2.0 (`.config/dotnet-tools.json`)

## 실행·접속 방식

### 로그인 없음 (v1.0.27~)

앱을 실행하면 **로그인 화면 없이** 바로 메인 화면이 열립니다.

작업 기록(감사 로그·전표 작성자)은 다음 순서로 결정됩니다.

1. DB에 활성 **관리자** 계정이 있으면 그 이름 사용
2. 없으면 **`local`** 관리자 계정을 자동 생성·사용

> 비밀번호는 로그인에 쓰이지 않습니다. 사용자 관리 화면은 계정·역할 관리용입니다.

## 메뉴 그룹 (v1.0.30~)

상단 네비게이션은 3그룹으로 묶여 있습니다.

| 그룹 | 탭 |
|------|-----|
| **업무** | 입출고, 재고 |
| **분석** | 대시보드, 통계 |
| **관리** | 백업, 설정, 사용자 |

자세한 화면 설명은 [03-화면-기능-구조.md](./03-화면-기능-구조.md)를 참고하세요.

## 데이터·백업 위치

설치 폴더와 DB는 **분리**되어 있습니다.

| 항목 | Windows 경로 |
|------|----------------|
| DB | `%LOCALAPPDATA%\SpringClinicInventory\inventory.db` |
| 로그 | `%LOCALAPPDATA%\SpringClinicInventory\logs\inventory-*.log` |
| 자동 백업 | `%LOCALAPPDATA%\SpringClinicInventory\backups\` (하루 첫 실행 1회) |
