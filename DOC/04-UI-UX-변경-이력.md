# 04 — UI/UX 변경 이력

의원 직원이 체감하는 화면·사용성 변경을 시간순으로 정리합니다.

---

## v1.0.51 — 최근 전표 필터는 직접 선택만

- 최근 전표 기본값: **전체**
- 새 전표에서 입고/출고를 바꿔도 최근 전표 필터는 그대로
- 최근 전표의 전체/입고/출고를 눌렀을 때만 목록이 바뀜

---

## v1.0.50 — 재고 목록에서 품목 삭제

- 입출고에서 전표를 지우면, 남은 재고·다른 유효 전표가 없을 때 **재고 메뉴에서도 품목이 사라짐**
- 재고 화면에 **삭제** 버튼 추가 (목록에서 숨김). 재고 수량이 남아 있으면 입출고 전표를 먼저 지우라는 안내

---

## v1.0.30~31 — 업무 메뉴 단순화 (Option A)

### 변경 내용

- **입고 + 출고 → 「입출고」 1탭**으로 통합
- 업무 그룹: **입출고 | 재고** 2탭만
- 새 전표는 **Expander** 안에 접어 두어 화면이 덜 복잡함
- 최근 전표: 입고·출고 **2섹션**, **유형 컬럼·필터 칩**
- 재고 화면에서 품목 선택 → **입출고 바로가기** (품목 자동 입력)

### v1.0.31 긴급 수정

- v1.0.30에서 입출고 탭 진입 시 **크래시** 발생 (DatePicker 중복)
- v1.0.31에서 **수정 완료**

## 디자인 리뷰 시 남은 항목 (참고)

아래는 scratchpad·커밋 메시지 기준으로 **추가 개선 여지**가 있을 수 있는 영역입니다. 현재 버전에서 모두 반영되었는지는 사용 중 확인이 필요합니다.

- 모바일/터치: 해당 없음 (데스크톱 전용)
- 접근성: WPF 기본 키보드 탐색
- 다크 모드: 미지원
- SmartScreen: 코드 서명 없음 → 설치 시 경고 가능 (정상)
